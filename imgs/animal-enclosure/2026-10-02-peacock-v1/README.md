# Pavão — arte original e movimento aprovados

Esta é a única pasta de referência do pavão. Os PNGs originais aprovados foram preservados sem alterações. Os JSONs contêm os pivôs de corpo aprovados no ciclo visual de 13/10/2026; o runtime usa cópias exatas dos dois pares PNG/JSON.

- `peacock-adult-poses.png` / `.json`: 1774 × 887 RGBA, estados `producing` e `ready`, cada um com `idle`, `walk-a`, `walk-b` e `preen`.
- `peachick-poses.png` / `.json`: 2172 × 724 RGBA, quatro poses do filhote.

Os PNGs foram gerados com o ImageGen integrado a partir da direção visual aprovada. Não foi usada arte de outro jogo. O leque aberto pertence ao sprite do adulto pronto; nenhuma pena solta define quantidade ou prontidão. A prontidão vem exclusivamente do snapshot aceito do servidor.

Os testes verificam igualdade dos PNG/JSON de runtime com esta fonte e os estados visuais do ciclo.
